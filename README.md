# Waterside Press

A digital library and household worship site: a seven-day Daily Liturgy, a small library of checked historic texts, and supporting pages. Static HTML generated by a dependency-free Node script.

## Run it

Requires Node 18 or later. No `npm install` step.

```sh
node build.mjs                                   # build into dist/ (relative links)
SITE_URL=https://your-domain.example node build.mjs   # production: adds canonical URLs, og:url, sitemap.xml
node tests/check.mjs                             # static checks: links, headings, metadata, ids
python3 tests/browser_test.py                    # optional: Playwright checks at phone and desktop widths
python3 -m http.server -d dist 8000              # preview at http://localhost:8000
```

## Deploy

`dist/` is a plain static site and works on any static host.

**Netlify:** `netlify.toml` is included (build `node build.mjs`, publish `dist`). Connect the repository or drag `dist/` into Netlify Drop. Set the environment variable `SITE_URL` to the final domain so the sitemap and canonical URLs are generated. Netlify serves `dist/404.html` for unknown paths automatically.

**Other hosts (GitHub Pages, Cloudflare Pages, any web server):** run the production build and upload `dist/`. Configure the host to serve `404.html` for missing pages.

Before going live: add the host's logging practice to the Privacy page (`content/pages.mjs`), and publish a contact address on the Copyright page once one exists.

## Structure

```
build.mjs              Generator: layout, header/footer, liturgy and library rendering, sitemap
content/liturgy.mjs    Seven days of liturgy as structured data (readings, songs, catechism, prayers)
content/library.mjs    Library records with edition, repository, rights, and PDF check status
content/pages.mjs      Home, Family Worship, Music, Learning, About, Editorial, Copyright, Privacy, Accessibility, Letter
src/assets/            site.css (design system, light/dark, print), site.js, liturgy.js, library.js
tests/                 check.mjs (static), browser_test.py (Playwright)
docs/                  Content manifest, sources & rights, withheld items, test report, next steps
```

**Adding a library work:** add a record to `content/library.mjs` only after completing the checks in `docs/SOURCES-AND-RIGHTS.md`. The card, detail page, search index, and filters are generated from the record.

**Adding or editing a liturgy day:** edit `content/liturgy.mjs`. Each element carries its source; the page labels Scripture, historic texts, and Waterside originals automatically.

## Design notes

Typography: EB Garamond (reading and headings) with Source Sans 3 (interface), loaded from Google Fonts (disclosed on the Privacy page; self-hosting is on the next-steps list). Palette: parchment, forest green, olive, brown, brass accent, with a dark mode. The emblem — a tree beside streams of water (Psalm 1:3) — is inline SVG and works in one colour at any size.

Timezone policy: the Daily Liturgy uses the visitor's device-local date. Without JavaScript all seven days are shown.
