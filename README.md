# Waterside Press

A digital library and household worship site: a Daily Office (Morning and Evening Prayer), Family Catechesis sessions, a small library of checked historic texts, and supporting pages. Static HTML generated by a dependency-free Node script.

## Run it

Requires Node 18 or later. No `npm install` step.

```sh
node build.mjs                                   # build into dist/ (relative links)
SITE_URL=https://your-domain.example node build.mjs   # production: adds canonical URLs, og:url, sitemap.xml
node tests/check.mjs                             # static checks: links, headings, metadata, ids
python3 tests/browser_test.py                    # optional: Playwright checks at phone and desktop widths
python3 -m http.server -d dist 8000              # preview at http://localhost:8000
```

## Deploy

`dist/` is a plain static site and works on any static host.

**Netlify:** `netlify.toml` is included (build `node build.mjs`, publish `dist`). Connect the repository or drag `dist/` into Netlify Drop. Set the environment variable `SITE_URL` to the final domain so the sitemap and canonical URLs are generated. Netlify serves `dist/404.html` for unknown paths automatically.

**Other hosts (GitHub Pages, Cloudflare Pages, any web server):** run the production build and upload `dist/`. Configure the host to serve `404.html` for missing pages.

Before going live: add the host's logging practice to the Privacy page (`content/pages.mjs`), and publish a contact address on the Copyright page once one exists.

## Structure

```
build.mjs              Generator: layout, Office, catechesis, Lord's Day, library rendering, sitemap
content/office.mjs     Daily Office texts, the 1662 psalter table, and the continuous-reading plan
content/catechesis.mjs Family Catechesis units and sessions (WSC questions, readings, discussion)
content/hymns.mjs      Psalm and hymn texts used by the Office and the Music page
content/library.mjs    Library records with edition, repository, rights, and PDF check status
content/pages.mjs      Home, Music, Learning, About, Editorial, Copyright, Privacy, Accessibility, Letter
src/assets/            site.css (design system, light/dark, print), site.js, office.js, library.js
tests/                 check.mjs (static), browser_test.py (Playwright)
docs/                  Content manifest, sources & rights, withheld items, test report, next steps
```

**Adding a library work:** add a record to `content/library.mjs` only after completing the checks in `docs/SOURCES-AND-RIGHTS.md`. The card, detail page, search index, and filters are generated from the record.

**Editing the Office:** edit `content/office.mjs`. Each element carries its source, and the page labels Scripture, historic texts, Waterside arrangements, and originals automatically.

**Adding catechesis sessions:** add a session (or a unit) to `content/catechesis.mjs`; its page, navigation, and landing-page entry are generated.

## Design notes

Direction: a private-press reading room. Parchment page, forest-green imprint, brass for ornament only, and prayer-book red for rubrics, with fine rules in place of boxes. All tokens (colour, type, spacing) are defined once at the top of `src/assets/site.css`, with a dark-mode set.

- **Type:** Cormorant Garamond (display), Source Serif 4 (reading), Source Sans 3 (controls and metadata), from Google Fonts (disclosed on the Privacy page). Fallback stacks are set; self-hosting is on the next-steps list.
- **Liturgical text** has five treatments: words to pray (serif), rubrics (red italic), Leader/All responses (red small-caps labels, bold responses), notes (collapsed, quiet), and reading directions (brass-ruled "Read today" block).
- **Contrast:** every text colour pair is at least 4.5:1 in both themes; form-control borders at least 3:1.
- **Breakpoints:** full navigation from 1080px; menu button below. Layouts tested at 375, 768, and 1280px.
- **Emblem:** a tree beside streams of water (Psalm 1:3), inline SVG, one colour, legible at favicon size. The home page uses a larger bookplate-style engraving of the same motif.

Date policy: the Daily Office uses the visitor's device-local date. Psalms follow the 1662 day-of-month psalter (the 30th day repeats on the 31st). Lessons follow a continuous-reading plan counted from 1 January 2026. Without JavaScript the page shows both weekday and Sunday forms and the full psalter table.
